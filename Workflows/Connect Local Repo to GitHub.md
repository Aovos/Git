# Create a Local Repo

### 1. [Create a Repository](../Modules/Create%20a%20Repository.md)

Initialize a new Git repository:

```bash
git init
```

### 2. [Git Identity](../Modules/Git%20Identity.md)

Configure the username and e-mail address used for commits:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

### 3. [Check Repository Status](../Modules/Check%20Repository%20Status.md)

Display the current repository status:

```bash
git status
```

### 4. [Stage Files](../Modules/Stage%20Files.md)

Stage all files for the first commit:

```bash
git add .
```

### 5. [Commit Changes](../Modules/Commit%20Changes.md)

Create the initial commit:

```bash
git commit -m "Initial commit"
```

### Result

You now have:

- A local Git repository
- A configured Git identity
- Staged files
- An initial commit
